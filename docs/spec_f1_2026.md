# Spécification Détaillée - Mise à Jour F1 2026

## 1. Introduction

### 1.1 Contexte Réglementaire F1 2026
La saison 2026 marque un changement majeur dans la réglementation technique de la Formule 1:

**Changements Principaux:**
- **Moteurs**: Suppression du MGU-H, augmentation de la part électrique (50/50 ICE/ERS)
- **ERS**: Puissance maximale portée à 350 kW (~470 HP), capacité illimitée (batteries rechargées par freinage)
- **Carburant**: 100% durable (advanced sustainable fuels), débit max augmenté à 150 kg/h
- **Aérodynamique**: Réduction de la traînée (-55%), ailerons actifs (X-Mode/Z-Mode)
- **Masse minimale**: Augmentation à 768 kg (sans carburant) due aux batteries plus grosses
- **Dimensions**: Empattement réduit de 20 cm, largeur réduite de 10 cm

### 1.2 Objectifs de la Mise à Jour
Adapter le simulateur RaceSim pour:
1. Implémenter les nouvelles spécifications techniques F1 2026
2. Modéliser le système ERS révisé (350 kW, pas de limite MJ)
3. Intégrer les modes aérodynamiques (X-Mode/Z-Mode)
4. Mettre à jour les configurations véhicules pour toutes les écuries
5. Ajouter le support des carburants durables

### 1.3 Périmètre Technique
- **Nouveaux modules**: `ers_2026.py`, `aero_active.py`, `fuel_sustainable.py`
- **Modules modifiés**: `engine.py` → `powertrain_2026.py`, `car.py` → `car_2026.py`
- **Configurations**: Tous les fichiers YAML voitures 2026
- **Circuits**: Mises à jour des tracés (Monza, Spa, etc. avec nouveaux layouts si changements)

#### 2.1.2 Système ERS Révisé

**Spécifications clés:**
- **MGU-K seul** (MGU-H supprimé)
- **Puissance max**: 350 kW (470 HP) vs 120 kW en 2024
- **Déploiement**: Libre au-delà de 290 km/h (X-Mode)
- **Récupération**: Uniquement au freinage (pas de récupération sur échappement)
- **Capacité batterie**: ~8-10 MJ (augmenté, mais rechargé chaque tour)
- **Temps de déploiement**: ~33 secondes par tour à pleine puissance

```python
# racesim/src/powertrain/ers_2026.py
from dataclasses import dataclass
from enum import Enum
from typing import Tuple

class ERSMode(Enum):
    """Modes de déploiement ERS 2026"""
    X_MODE = 0      # Mode qualification - puissance max, traînée réduite
    Z_MODE = 1      # Mode course - downforce normale
    CHARGING = 2    # Priorité recharge batterie
    DEFENDING = 3   # Protection position (déploiement défensif)
    ATTACKING = 4   # Attaque DRS + ERS boost

@dataclass
class ERSConfig2026:
    """Configuration ERS F1 2026"""
    power_max_kw: float = 350.0  # kW (réglementaire)
    energy_per_lap_mj: float = 8.5  # MJ typique déployé par tour
    recovery_max_kw: float = 850.0  # kW en récupération freinage
    min_deploy_speed_kmh: float = 290.0  # Vitesse min pour déploiement libre
    battery_capacity_mj: float = 10.0  # Capacité max batterie
    battery_min_soc: float = 0.2  # État de charge minimum (20%)
    efficiency_motor: float = 0.95  # Rendement MGU-K
    efficiency_inverter: float = 0.97  # Rendement onduleur
    
class ERS2026:
    """Système ERS F1 2026 - MGU-K uniquement"""
    
    def __init__(self, config: ERSConfig2026):
        self.config = config
        self.mode = ERSMode.Z_MODE
        self.battery_energy_j = 4.0e6  # 4 MJ initial (50% SOC)
        self.deployment_power_w = 0.0
        self.recovery_power_w = 0.0
        self.temp_motor = 80.0  # °C
        self.temp_inverter = 60.0  # °C
        
        # Courbe de puissance disponible selon régime
        self._load_power_curve()
        
    def _load_power_curve(self):
        """Courbe de puissance MGU-K 2026"""
        # Données approximatives basées sur spécifications FIA
        import numpy as np
        self.rpm_points = np.array([0, 5000, 10000, 15000, 20000])
        self.power_points = np.array([0, 100000, 300000, 350000, 350000])  # Watts
        
    def get_available_power(self, rpm: float, velocity_kmh: float) -> float:
        """
        Calcule la puissance ERS disponible
        
        Args:
            rpm: Régime moteur [1/min]
            velocity_kmh: Vitesse véhicule [km/h]
            
        Returns:
            Puissance disponible [W]
        """
        # Limite de base selon RPM
        base_power = float(np.interp(rpm, self.rpm_points, self.power_points))
        
        # Restriction selon mode
        if self.mode == ERSMode.X_MODE:
            # X-Mode: puissance max au-delà de 290 km/h
            if velocity_kmh >= self.config.min_deploy_speed_kmh:
                power_limit = self.config.power_max_kw * 1000
            else:
                # Progressif avant 290 km/h
                ratio = velocity_kmh / self.config.min_deploy_speed_kmh
                power_limit = self.config.power_max_kw * 1000 * ratio
        elif self.mode == ERSMode.CHARGING:
            # Priorité recharge, pas de déploiement
            power_limit = 0.0
        elif self.mode == ERSMode.DEFENDING:
            # Déploiement réduit pour économiser
            power_limit = self.config.power_max_kw * 1000 * 0.6
        else:  # Z_MODE normal ou ATTACKING
            power_limit = self.config.power_max_kw * 1000 * 0.85
            
        # Limite par état de charge batterie
        min_energy = self.config.battery_capacity_mj * 1e6 * self.config.battery_min_soc
        if self.battery_energy_j <= min_energy:
            power_limit = min(power_limit, 50000)  # 50 kW max si batterie faible
            
        return min(base_power, power_limit)
        
    def deploy(self, requested_power_w: float, duration_s: float, 
               rpm: float, velocity_kmh: float) -> float:
        """
        Déploie de la puissance ERS
        
        Returns:
            Énergie réellement déployée [J]
        """
        # Puissance disponible réelle
        available_power = self.get_available_power(rpm, velocity_kmh)
        actual_power = min(requested_power_w, available_power)
        
        # Énergie requise
        required_energy = actual_power * duration_s
        
        # Vérifier énergie disponible en batterie
        min_energy = self.config.battery_capacity_mj * 1e6 * self.config.battery_min_soc
        usable_energy = self.battery_energy_j - min_energy
        
        # Limiter à l'énergie disponible
        actual_energy = min(required_energy, usable_energy)
        
        # Mettre à jour batterie
        self.battery_energy_j -= actual_energy
        
        # Chauffage moteur/inverter
        losses = actual_energy * (1 - self.config.efficiency_motor * self.config.efficiency_inverter)
        self.temp_motor += losses * 0.0001  # Simplifié
        self.temp_inverter += losses * 0.00015
        
        return actual_energy
        
    def recover(self, brake_power_w: float, duration_s: float) -> float:
        """
        Récupère de l'énergie au freinage
        
        Args:
            brake_power_w: Puissance de freinage disponible [W]
            duration_s: Durée du freinage [s]
            
        Returns:
            Énergie stockée [J]
        """
        # Limite de récupération
        max_recovery = self.config.recovery_max_kw * 1000
        available_recovery = min(brake_power_w, max_recovery)
        
        # Énergie brute récupérée
        raw_energy = available_recovery * duration_s
        
        # Pertes de conversion
        recovered_energy = raw_energy * self.config.efficiency_motor * self.config.efficiency_inverter
        
        # Limite capacité batterie
        max_storage = self.config.battery_capacity_mj * 1e6 - self.battery_energy_j
        actual_stored = min(recovered_energy, max_storage)
        
        # Mettre à jour batterie
        self.battery_energy_j += actual_stored
        
        return actual_stored
        
    def set_mode(self, mode: ERSMode):
        """Change le mode de déploiement"""
        self.mode = mode
        
    def get_soc(self) -> float:
        """Retourne l'état de charge (0-1)"""
        return self.battery_energy_j / (self.config.battery_capacity_mj * 1e6)
        
    def update_cooling(self, ambient_temp: float, dt: float):
        """Met à jour les températures"""
        # Refroidissement liquide simplifié
        cooling_rate_motor = 0.1
        cooling_rate_inverter = 0.15
        
        self.temp_motor -= (self.temp_motor - ambient_temp) * cooling_rate_motor * dt
        self.temp_inverter -= (self.temp_inverter - ambient_temp) * cooling_rate_inverter * dt
        
        # Clamp
        self.temp_motor = max(40, min(150, self.temp_motor))
        self.temp_inverter = max(30, min(120, self.temp_inverter))
```

### 2.2 Aérodynamique Active (X-Mode/Z-Mode)

#### 2.2.1 Spécifications

**Z-Mode (Mode Course Normal):**
- Downforce maximale
- Traînée élevée
- Utilisé dans la majorité des tours

**X-Mode (Mode Faible Traînée):**
- Activable uniquement au-delà de 290 km/h
- Réduction de traînée: ~55%
- Réduction de downforce: ~30%
- Utilisé pour les dépassements et qualifications

```python
# racesim/src/aero/active_aero_2026.py
from enum import Enum
from dataclasses import dataclass

class AeroMode(Enum):
    Z_MODE = 0  # Downforce normale
    X_MODE = 1  # Faible traînée

@dataclass
class AeroConfig2026:
    """Configuration aérodynamique F1 2026"""
    # Z-Mode (normal)
    cda_z_mode: float = 1.45  # m² (traînée)
    cz_front_z: float = 2.80  # m² (downforce avant)
    cz_rear_z: float = 3.40   # m² (downforce arrière)
    
    # X-Mode (low drag)
    cda_x_mode: float = 0.65  # m² (-55% vs Z-Mode)
    cz_front_x: float = 2.10  # m² (-25%)
    cz_rear_x: float = 2.40   # m² (-29%)
    
    # Conditions d'activation
    min_speed_x_mode_kmh: float = 290.0
    activation_time_s: float = 0.3  # Temps pour changer de mode
    
class ActiveAeroSystem:
    """Système d'aérodynamique active F1 2026"""
    
    def __init__(self, config: AeroConfig2026):
        self.config = config
        self.current_mode = AeroMode.Z_MODE
        self.target_mode = AeroMode.Z_MODE
        self.transition_timer = 0.0
        self.transition_progress = 0.0  # 0 = Z-Mode, 1 = X-Mode complet
        
    def request_mode(self, mode: AeroMode, current_speed_kmh: float) -> bool:
        """
        Demande un changement de mode aérodynamique
        
        Returns:
            True si la demande est valide, False sinon
        """
        if mode == AeroMode.X_MODE:
            # Vérifier condition de vitesse minimale
            if current_speed_kmh < self.config.min_speed_x_mode_kmh:
                return False
                
        self.target_mode = mode
        
        # Démarrer transition si changement nécessaire
        if self.current_mode != self.target_mode:
            self.transition_timer = self.config.activation_time_s
            
        return True
        
    def update(self, dt: float, current_speed_kmh: float):
        """Met à jour l'état du système"""
        if self.transition_timer > 0:
            # Transition en cours
            self.transition_timer -= dt
            
            if self.transition_timer <= 0:
                # Transition terminée
                self.current_mode = self.target_mode
                self.transition_progress = 1.0 if self.current_mode == AeroMode.X_MODE else 0.0
            else:
                # Progression de la transition
                progress = 1.0 - (self.transition_timer / self.config.activation_time_s)
                self.transition_progress = progress if self.target_mode == AeroMode.X_MODE else (1.0 - progress)
                
        # Auto-désactivation X-Mode si vitesse trop basse
        if (self.current_mode == AeroMode.X_MODE and 
            current_speed_kmh < self.config.min_speed_x_mode_kmh * 0.9):
            self.request_mode(AeroMode.Z_MODE, current_speed_kmh)
            
    def get_drag_area(self) -> float:
        """Retourne la surface de traînée actuelle (interpolée)"""
        if self.current_mode == self.target_mode:
            # Mode stable
            return self.config.cda_x_mode if self.current_mode == AeroMode.X_MODE else self.config.cda_z_mode
        else:
            # Interpolation pendant transition
            return (self.config.cda_z_mode * (1 - self.transition_progress) + 
                    self.config.cda_x_mode * self.transition_progress)
                    
    def get_downforce_coefficients(self) -> Tuple[float, float]:
        """
        Retourne les coefficients de downforce (avant, arrière)
        
        Returns:
            (cz_front, cz_rear) en m²
        """
        if self.current_mode == self.target_mode:
            if self.current_mode == AeroMode.X_MODE:
                return self.config.cz_front_x, self.config.cz_rear_x
            else:
                return self.config.cz_front_z, self.config.cz_rear_z
        else:
            # Interpolation
            cz_front = (self.config.cz_front_z * (1 - self.transition_progress) + 
                       self.config.cz_front_x * self.transition_progress)
            cz_rear = (self.config.cz_rear_z * (1 - self.transition_progress) + 
                      self.config.cz_rear_x * self.transition_progress)
            return cz_front, cz_rear
            
    def is_x_mode_available(self, speed_kmh: float) -> bool:
        """Vérifie si le X-Mode peut être activé"""
        return speed_kmh >= self.config.min_speed_x_mode_kmh
        
    def get_current_mode(self) -> AeroMode:
        """Retourne le mode actuel"""
        return self.current_mode
```

### 2.3 Carburants Durables

#### 2.3.1 Spécifications

**Carburant F1 2026:**
- 100% avancé et durable (bio-sourcé ou synthèse)
- Même densité énergétique que l'essence fossile (~44 MJ/kg)
- Légèrement moins efficace en combustion (-2% puissance)
- Compatible avec les moteurs actuels (adaptés)

```python
# racesim/src/powertrain/fuel_sustainable.py
from dataclasses import dataclass

@dataclass
class SustainableFuelSpecs:
    """Spécifications carburant durable F1 2026"""
    name: str = "Advanced Sustainable Fuel"
    density_kg_l: float = 0.755  # kg/L (similaire à l'essence)
    energy_content_mj_kg: float = 43.5  # MJ/kg (vs 44.4 pour fossile)
    octane_rating: int = 102
    oxygen_content_percent: float = 2.5  # Oxygéné pour meilleure combustion
    co2_reduction_vs_fossil: float = 0.65  # -65% émissions CO2 cycle de vie
    
class FuelSystem2026:
    """Système de carburant durable"""
    
    def __init__(self, fuel_specs: SustainableFuelSpecs, tank_capacity_kg: float = 110.0):
        self.specs = fuel_specs
        self.tank_capacity_kg = tank_capacity_kg
        self.fuel_remaining_kg = tank_capacity_kg
        self.flow_rate_kg_s = 0.0
        self.total_consumed_kg = 0.0
        
        # Limites réglementaires
        self.max_flow_rate_kg_h = 150.0  # kg/h (augmenté vs 100)
        self.max_flow_rate_kg_s = self.max_flow_rate_kg_h / 3600.0
        
    def consume(self, power_demand_w: float, duration_s: float, 
                engine_efficiency: float) -> float:
        """
        Calcule et consomme le carburant pour une demande de puissance
        
        Args:
            power_demand_w: Puissance demandée [W]
            duration_s: Durée [s]
            engine_efficiency: Rendement du moteur (0-1)
            
        Returns:
            Masse de carburant consommée [kg]
        """
        # Énergie requise
        energy_required_j = power_demand_w * duration_s
        
        # Énergie disponible dans le carburant
        energy_per_kg_j = self.specs.energy_content_mj_kg * 1e6
        
        # Carburant nécessaire (considérant rendement)
        fuel_needed_kg = energy_required_j / (energy_per_kg_j * engine_efficiency)
        
        # Limite de débit
        max_fuel_flow = self.max_flow_rate_kg_s * duration_s
        actual_fuel = min(fuel_needed_kg, max_fuel_flow, self.fuel_remaining_kg)
        
        # Mettre à jour réservoir
        self.fuel_remaining_kg -= actual_fuel
        self.total_consumed_kg += actual_fuel
        
        return actual_fuel
        
    def get_remaining_laps(self, consumption_per_lap_kg: float) -> float:
        """Estime le nombre de tours restants"""
        return self.fuel_remaining_kg / consumption_per_lap_kg
        
    def get_fuel_mass_effect(self) -> float:
        """Retourne l'effet de la masse de carburant sur la performance"""
        # Chaque kg de carburant ajoute du poids
        # Impact: ~0.03s/tour par 10kg en F1
        fuel_mass_fraction = self.fuel_remaining_kg / self.tank_capacity_kg
        return fuel_mass_fraction
        
    def calculate_optimal_strategy(self, race_laps: int, 
                                   target_consumption_kg: float) -> dict:
        """
        Calcule une stratégie de consommation optimale
        
        Returns:
            Dict avec recommandations de gestion carburant
        """
        avg_consumption_needed = target_consumption_kg / race_laps
        
        if self.fuel_remaining_kg < target_consumption_kg:
            return {
                "status": "CRITICAL",
                "message": "Pas assez de carburant pour finir",
                "shortage_kg": target_consumption_kg - self.fuel_remaining_kg,
                "recommended_mode": "SAVE_FUEL_EXTREME"
            }
        elif self.fuel_remaining_kg > target_consumption_kg * 1.05:
            return {
                "status": "SURPLUS",
                "message": "Carburant excédentaire, pousser plus",
                "surplus_kg": self.fuel_remaining_kg - target_consumption_kg,
                "recommended_mode": "QUALIFY"
            }
        else:
            return {
                "status": "OPTIMAL",
                "message": "Stratégie dans la fenêtre",
                "margin_kg": self.fuel_remaining_kg - target_consumption_kg,
                "recommended_mode": "RACE"
            }
```

```python
        Args:
            dt: Pas de temps [s]
            inputs: {throttle, brake, steer, ers_mode, aero_mode}
        """
        # Gérer mode aérodynamique
        speed_kmh = self.velocity.magnitude() * 3.6
        self.aero_system.request_mode(inputs['aero_mode'], speed_kmh)
        self.aero_system.update(dt, speed_kmh)
        
        # Calculer forces aérodynamiques
        drag_area = self.aero_system.get_drag_area()
        downforce_f, downforce_r = self.aero_system.get_downforce_coefficients()
        
        aero_drag = 0.5 * 1.18 * drag_area * self.velocity.magnitude()**2
        aero_downforce = 0.5 * 1.18 * (downforce_f + downforce_r) * self.velocity.magnitude()**2
        
        # Mettre à jour groupe motopropulseur
        power_request = inputs['throttle'] * self.powertrain.max_power
        ers_mode = inputs['ers_mode']
        
        ice_torque, ers_torque, fuel_consumed = self.powertrain.produce_power(
            power_request,
            ers_mode,
            self.rpm,
            speed_kmh,
            dt
        )
        
        # Couple total aux roues
        total_torque = (ice_torque + ers_torque) * self.gearbox.current_ratio
        
        # Accélération (F = ma, avec forces aérodynamiques)
        traction_force = total_torque / self.tire_radius
        net_force = traction_force - aero_drag - rolling_resistance
        acceleration = net_force / self.mass_total
        
        # Mise à jour physique
        self.velocity += acceleration * dt
        self.position += self.velocity * dt
        
        # Masse mise à jour (carburant consommé)
        self.mass_total = self.mass_empty + self.powertrain.fuel_remaining_kg
```
