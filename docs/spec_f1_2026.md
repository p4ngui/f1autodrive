## 3. Spécifications Techniques 2026

### 3.1 Système ERS 2026 (350 kW)

#### 3.1.1 Architecture
```python
class ERS2026:
    def __init__(self):
        # Batterie : capacité augmentée pour supporter 350kW
        self.battery_capacity_mj = 45.0  # ~12.5 kWh (vs 20 MJ ~5.5 kWh en 2024)
        self.max_soc = 1.0
        self.min_soc = 0.20
        
        # MGU-K : puissance triplée
        self.mguk_max_power_kw = 350.0  # vs 120 kW en 2024
        
        # Limites réglementaires 2026
        self.max_energy_per_lap_mj = 8.5  # Déploiement max par tour
        self.max_recovery_per_lap_mj = 4.5  # Récupération MGU-K
        
        # Plus de MGU-H en 2026
        self.has_mgu_h = False
    
    def deploy_power(self, demand_kw: float, soc: float, 
                     lap_distance_m: float, speed_kmh: float) -> float:
        """
        Déploiement ERS avec stratégie 2026
        - 350kW disponible sur lignes droites
        - Gestion énergie critique (8.5 MJ/tour)
        """
        # Vérifier limites
        if self.energy_deployed_lap >= self.max_energy_per_lap_mj:
            return 0.0
        
        available_energy = (soc - self.min_soc) * self.battery_capacity_mj
        
        # Stratégie : puissance max au-delà de 200 km/h (typique deployment zone)
        if speed_kmh > 200:
            power_kw = min(self.mguk_max_power_kw, demand_kw)
        else:
            power_kw = min(self.mguk_max_power_kw * 0.5, demand_kw)  # Réduit en basse vitesse
        
        # Limite par énergie restante
        remaining_allowed = self.max_energy_per_lap_mj - self.energy_deployed_lap
        max_power_by_energy = remaining_allowed * 500  # Conversion approximative
        
        final_power = min(power_kw, max_power_by_energy, available_energy * 3)
        
        return final_power
    
    def recover_power(self, braking_power_kw: float, throttle_position: float) -> float:
        """
        Récupération uniquement via MGU-K (plus de MGU-H)
        - Freinage régénératif
        - Lever de pied (engine braking)
        """
        if not self.has_mgu_h:
            # Seulement MGU-K
            mgu_k_recovery = min(
                braking_power_kw * 0.4,  # 40% efficacité récupération
                (self.max_recovery_per_lap_mj - self.energy_recovered_lap) / 0.1  # Par seconde
            )
            return mgu_k_recovery
        else:
            # Code 2024 avec MGU-H (ne sera pas exécuté en 2026)
            pass
```

#### 3.1.2 Impacts Performance
- **Accélération 200→300 km/h** : Réduite de ~1.5s grâce aux 350kW supplémentaires.
- **Vitesse Max** : Augmentée de 15-20 km/h sur circuits rapides (Monza, Baku).
- **Stratégie Course** : Gestion énergie plus critique (8.5 MJ vs 4.0 MJ).

### 3.2 Aérodynamique Active (X-Mode / Z-Mode)

#### 3.2.1 Principe de Fonctionnement
- **X-Mode** : Activé au-delà de 290 km/h → réduction traînée 55%.
- **Z-Mode** : En dessous de 290 km/h ou freinage → appui maximal.
- **Transition** : Sigmoïde pour éviter discontinuités physiques.

#### 3.2.2 Implémentation
```python
class ActiveAeroSystem:
    def __init__(self, threshold_speed_kmh: float = 290.0, 
                 drag_reduction: float = 0.55):
        self.threshold_speed = threshold_speed_kmh
        self.drag_reduction = drag_reduction
        self.current_mode = 'Z'  # Z-Mode par défaut (appui max)
        self.transition_width = 20.0  # km/h (zone de transition sigmoïde)
    
    def get_aero_coefficients(self, speed_kmh: float, 
                              braking: bool) -> Tuple[float, float]:
        """
        Retourne (Cx, Cz) selon mode actif
        """
        # Base coefficients (Z-Mode)
        cx_base = 0.95
        cz_base = 3.8
        
        # Déterminer mode cible
        if braking or speed_kmh < (self.threshold_speed - self.transition_width/2):
            target_mode = 'Z'
            cx_target = cx_base
            cz_target = cz_base
        elif speed_kmh > (self.threshold_speed + self.transition_width/2):
            target_mode = 'X'
            cx_target = cx_base * (1 - self.drag_reduction)  # -55% traînée
            cz_target = cz_base * 0.7  # Perte appui ~30% en X-Mode
        else:
            # Zone de transition : interpolation sigmoïde
            t = (speed_kmh - self.threshold_speed) / self.transition_width
            sigmoid = 1 / (1 + np.exp(-t * 10))  # Pente raide
            cx_target = cx_base * (1 - self.drag_reduction * sigmoid)
            cz_target = cz_base * (1 - 0.3 * sigmoid)
            target_mode = 'TRANSITION'
        
        # Smooth transition (éviter sauts brusques)
        alpha = 0.1  # Facteur lissage temporel
        self.current_cx = (1 - alpha) * getattr(self, 'current_cx', cx_target) + alpha * cx_target
        self.current_cz = (1 - alpha) * getattr(self, 'current_cz', cz_target) + alpha * cz_target
        
        return self.current_cx, self.current_cz
```

#### 3.2.3 Validation Physique
- **Continuité C²** : La sigmoïde assure dérivées continues (pas de chocs numériques).
- **Conservation Énergie** : Réduction traînée → vitesse max augmentée cohérente.
- **Comportement Freinage** : Passage automatique en Z-Mode (<290 km/h ou braking).

### 3.3 Suppression MGU-H

#### 3.3.1 Impact Architecture
En 2026, le MGU-H est supprimé :
- **Récupération énergie** : Uniquement via MGU-K (freinage + engine braking).
- **Turbo Lag** : Plus compensé par MGU-H → lag plus perceptible.
- **Complexité** : Réduite (moins de composants).

#### 3.3.2 Adaptation Code
```python
class PowertrainAssembly:
    def __init__(self, components: List[Component], year: int):
        self.year = year
        self.components = {c.name: c for c in components}
        
        # Vérifier présence MGU-H selon année
        if year >= 2026:
            assert 'MGU-H' not in self.components, "MGU-H interdit depuis 2026"
    
    def harvest_energy(self, exhaust_energy: float, braking_energy: float):
        # 2024-2025 : MGU-H + MGU-K
        if self.year < 2026:
            mgu_h_recovery = self.components['MGU-H'].harvest(exhaust_energy)
        else:
            mgu_h_recovery = 0.0  # Supprimé
        
        # Toutes années : MGU-K
        mgu_k_recovery = self.components['MGU-K'].recover(braking_energy)
        
        return mgu_h_recovery + mgu_k_recovery
```

### 3.4 Moteur Thermique 2026

#### 3.4.1 Caractéristiques
- **Carburant 100% Durable** : Pouvoir calorifique légèrement différent.
- **Débit Réduit** : ~85 kg/h vs 100 kg/h (économie imposée).
- **Puissance ICE** : Légèrement réduite pour compenser ERS accru (~550 kW vs 630 kW).

#### 3.4.2 Modèle Combustion
```python
class ICEngine2026(ICEngine):
    def __init__(self):
        super().__init__()
        # Carburant durable : pouvoir calorifique ~98% vs fossile
        self.fuel_energy_density = 42.0  # MJ/kg (vs 42.8 fossile)
        self.max_fuel_flow_kg_h = 85.0   # Réduit vs 100 kg/h
    
    def get_power_from_fuel(self, fuel_flow_kg_s: float) -> float:
        # Puissance = débit × densité énergie × rendement
        power_w = fuel_flow_kg_s * self.fuel_energy_density * 1e6 * 0.50  # 50% rendement thermique
        return power_w / 1000.0  # kW
```
